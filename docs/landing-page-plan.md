# Landing page plan

Status: content structure ready; visual direction and example treatment pending. No website built or deployed.

## Audience and promise

Designers using coding agents to turn a brief into an interactive prototype and an evidence-based case study.

Proposed headline: From product brief to a prototype you can explain.

Supporting line: A shared workflow for framing the problem, building complete journeys, checking recovery paths, and presenting the decisions.

Primary action: Get the skills. Secondary action: Explore the workflow.

## Page sequence

1. Hero: outcome, concise explanation, installation link and one approved product visual.
2. What you can make: two compact examples, each pairing a prototype detail with a product-image treatment. Label these as earlier work using similar methods.
3. Three connected skills: coordination, interaction prototype and product case study. Explain the responsibility of each without repeating the full skill documentation.
4. Workflow: brief and scope, parallel prototype and narrative, verification, optional imagery, release and rehearsal. Include a return path for concrete defects.
5. Designed to improve: observed failure, regression scenario, candidate change, comparison and maintainer review. State that no unattended self-rewriting is enabled.
6. Start using it: host-specific install instructions, optional imagery companion and links to detailed documentation.
7. Evidence and contribution: research sources, current validation limits, contribution guide and license.

## Example treatment

Use generic captions such as activation and onboarding. Original captures remain local selection material because identifying UI details are visible. Inspect and generalize those details before publishing. Do not imply that this newly packaged skill produced the earlier projects, or that the imagery proves working functionality.

A full-page case-study screenshot is unnecessary. Favor a readable interaction detail and a complementary product image. Preserve the original privately and label edited examples accurately.

## Visual direction to resolve

Proposed: warm editorial product photography, level UI, restrained typography, generous spacing and minimal panels. The existing imagery is a possible reference, not an approved new brand direction.

## Acceptance

- A reader can identify the outcome, three skills and installation path quickly.
- Examples have accurate provenance and approved disclosure.
- Core content remains readable without animation or image loading.
- Desktop and narrow layouts, keyboard navigation and links are checked.
- Claims distinguish packaging tests from behavioral evaluation.
- No changes to the original case-study sites are needed.
