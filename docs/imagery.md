# Product imagery integration

The pinned companion suite provides product-only imagery, persona scenes and brand intake. Read its relevant skill before production. Its runtime does not include an image model; generation depends on the host's available tools. Use host-authorized editing and compositing capabilities, and do not substitute unsupported tools.

## Place in the workflow

After a prototype passes the selected interaction checks, capture the exact state and viewport. Ask for brand or visual references before committing to a creative direction. A neutral placeholder requires explicit approval. Choose the role of each image: hero, feature explanation, workflow example or share preview. Avoid producing a large image set without a presentation need.

Route product-only work to saas-product-imagery; scenes with people or human traces to saas-persona-imagery; missing art direction to brand-imagery-director. Prefer level, legible screens when showing UI. Preserve source aspect ratio and important text. Inspect the final output against the source and again at its intended page size. Keep external titles in accessible page text where possible.

Record source revision, image purpose, generation/editing method, any fidelity limitations and output path. A source UI change marks the image stale. Synthetic scenes illustrate concepts; they do not establish working features.

## Public examples

Company-specific screenshots are not automatically anonymous after a heading changes. Inspect logos, domains, product names, navigation, map labels, user records and file metadata. Prefer newly authored fictional UI or an explicitly approved generalized capture. Preserve the original privately; never imply a generated recreation is an exact capture or a proven result of this skill release.

The package currently contains no showcase images. Select references and approve a public visual direction before building the separate landing page.
