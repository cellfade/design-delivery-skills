# Public showcase

The static landing page lives in `site/` and deploys through GitHub Pages on changes to that directory. It has no build dependencies or analytics.

The warm editorial direction and company-neutral examples were approved by the project owner. The gallery contains illustrative adaptations, not functional screenshots or benchmark claims. See `site/assets/README.md` for provenance.

Local preview: `python3 -m http.server 3417 --directory site`.

Release checks: inspect desktop and narrow-screen layouts, confirm image loading and no horizontal overflow, exercise the validation disclosure and installation copy button, then verify the deployed page. Original source captures and local QA screenshots remain excluded from publication.
