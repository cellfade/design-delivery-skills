04 / Learn without losing the plot

Improve the workflow.
Keep the evidence.

Real mistakes become test cases. Useful changes become reviewed updates.

Capture a failure, test a focused change, compare the results, and propose a pull request. The skills do not rewrite themselves or silently change your setup.

Read the learning protocol ↗
What has been validated?

Skill structure, local links, eight core installer tests and fifteen companion-suite tests have passed. Cross-model behavioral trials are still pending. These checks do not prove better design outcomes.
